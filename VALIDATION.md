# Weryfikacja

Wykonano kontrolę składni JavaScript oraz sprawdzenie lokalnych odnośników, unikalności identyfikatorów i istnienia plików używanych przez stronę. Wszystkie kontrole zakończyły się pomyślnie.

Pierwotny podgląd lokalny był niedostępny. Po publikacji na GitHub Pages wykonano dodatkowe kontrole dostępności i interakcji opisane w `ACCESSIBILITY.md`. Pełna macierz przeglądarek, powiększeń i technologii wspomagających pozostaje do wykonania.

Nie przeprowadzono migracji treści z Joomla ani testów istniejącego formularza. Nowy projekt nie zawiera backendu do przesyłania wiadomości. Brakujące dane kontaktowe i prawne są jawnie opisane w README.

Stronę opublikowano na GitHub Pages. Nie zmieniono konfiguracji dotychczasowego serwera.
